# GitHub Badge Achievements Guide

Status and sources checked on 4 November 2026. Numerical thresholds below are from the [community-maintained catalogue](https://github.com/Schweinepriester/github-profile-achievements#achievements), not a guaranteed GitHub counting contract.

| Achievement | Reported qualifying activity | Tiers |
| --- | --- | --- |
| Pull Shark | Pull requests merged | 2 / 16 / 128 / 1,024: base / Bronze / Silver / Gold |
| Pair Extraordinaire | Co-authored commits in merged pull requests | 1 / 10 / 24 / 48: base / Bronze / Silver / Gold |
| Galaxy Brain | Accepted discussion answers | 2 / 8 / 16 / 32: base / Bronze / Silver / Gold |
| Starstruck | Stars on one created repository | 16 / 128 / 512 / 4,096: base / Bronze / Silver / Gold |
| Quickdraw | Close an issue or pull request within five minutes of opening | Single award |
| YOLO | Merge an own pull request without code review | Single award |

GitHub Community Discussions do not award achievements. Repository rules still govern contributions; acceptance and stars belong to other participants. Shared work must receive accurate author credit. Using another account does not create another person's contribution.

See the [verified tracker](badge-tracker.md). GitHub awards achievements automatically; only the displayed profile confirms the awarded tier.
